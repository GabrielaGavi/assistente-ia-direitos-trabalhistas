KERNEL 1.0.0

A midnight instrument for developer tools

KERNEL is a design system for issue trackers, CI/CD, observability and API platform sites. Near-black surfaces, paper-white type at tight tracking, hairline edges, and one acid-lime accent that marks the single action that matters.
